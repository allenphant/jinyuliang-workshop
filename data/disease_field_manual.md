# 《金玉良炎疾病工作手冊》

> **完全虛構聲明**：金玉良炎、筵露菌、`Yanyulon convivii`、所有檢驗名稱、地點、人物、食品與事件皆為合成教學設定，不對應真實疾病、病原或歷史事件。本手冊是本案例唯一可採用的醫學與公衛知識來源。

## 1. 疾病與病原

- 疾病：金玉良炎，資料代碼 `jinyuliang_gastroenteritis`。
- 病原：筵露菌，虛構學名 `Yanyulon convivii`。
- 致病因子：`YL-A` 腸毒因子。
- 筵露菌可在高含水量冷食中繁殖，進入人體後短暫定殖並產生 `YL-A`。

## 2. 傳播方式

主要途徑是食用受到筵露菌污染且保存不當的食品。疾病不經空氣或飛沫傳播，單純與病例同處一室不構成有效暴露。

受污染的手可能造成極少量糞口二次傳播，但不會形成持續人傳人鏈；一般二次侵襲率低於 3%。標準事件預期沒有或最多只有一個二次病例。

## 3. 溫度、保存時間與風險

| 食品條件 | 筵露菌行為 |
|---|---|
| ≤5°C | 8 小時內幾乎不繁殖 |
| 6–15°C | 緩慢繁殖 |
| 16–25°C | 約每 2.5–3.5 小時倍增 |
| 26–37°C | 約每 45–75 分鐘倍增 |
| ≥70°C 持續 2 分鐘 | 可有效殺死活菌 |
| 殺菌後再次污染 | 仍可重新產生風險 |

風險由初始污染、保存溫度、保存時間及攝入量共同決定。一次偏高的溫度紀錄不代表每一份食品都一定致病。

## 4. 潛伏期分布

食源性有症狀感染者的潛伏期服從截尾 log-normal 分布：

- 中位數約 11 小時。
- 約 50% 在餐後 8–16 小時發病。
- 約 90% 在餐後 5–28 小時發病。
- 合理生物範圍為餐後 3–48 小時。
- 攝入劑量較高者平均較早發病，但個人差異仍然存在。

## 5. 症狀與病程

有症狀感染者的邊際症狀機率如下；症狀之間並非彼此獨立。

| 症狀欄位 | 說明 | 機率 |
|---|---|---:|
| `nausea` | 噁心 | 82% |
| `abdominal_cramps` | 腹部絞痛 | 78% |
| `diarrhea` | 腹瀉 | 72% |
| `vomiting` | 嘔吐 | 68% |
| `fatigue` | 倦怠 | 45% |
| `headache` | 頭痛 | 24% |
| `low_grade_fever` | 低度發熱 | 14% |
| `dizziness` | 暈眩 | 8% |
| `rash` | 皮疹 | 2% |

- 中位病程約 30 小時，約 90% 在 14–72 小時內恢復。
- 約 65% 輕症、32% 中度、3% 重症。
- 本案例預期極少住院，沒有死亡。

## 6. 無症狀感染

約 15% 感染者沒有足以符合臨床病例定義的症狀。無症狀檢驗陽性者是感染者，但不自動列為臨床病例。食用受污染食品也不代表一定感染或發病。

## 7. 檢驗

### `YL-NAAT`

| 相對發病採檢時間 | 敏感度 |
|---|---:|
| 0–24 小時 | 94% |
| 24–48 小時 | 86% |
| 48–72 小時 | 70% |
| >72 小時 | 45% |

- 特異度 99%。
- 陽性表示檢體中存在筵露菌核酸，但不能單獨證明感染發生於本次宴席。
- 陰性不能排除感染，尤其是延遲採檢者。

### `YL-Culture`

- 病人檢體敏感度約 78%，食品檢體約 82%。
- 特異度約 99.5%。
- 低菌量、保存不當或採檢過晚都可能造成陰性。

### `YL-Subtype`

病人與食品具有相同罕見型別是很強的支持證據，但仍需配合時間、場所與暴露鏈。

### 無關發現

`Petalomyces innocua` 是不會造成金玉良炎的虛構環境菌。它可能出現在潮濕器皿表面，檢出它不能證明盛裝該器皿的飲料造成群聚。

## 8. 病例定義

### 主要病例定義 `primary`

同時符合：

1. 參加千秋宴；
2. 發病介於個人用餐結束後 4–36 小時；
3. 符合下列任一條件：
   - `nausea`、`vomiting`、`diarrhea`、`abdominal_cramps` 至少兩項；
   - `vomiting_count_24h >= 2`；
   - `loose_stool_count_24h >= 3`。

主要病例定義不納入檢驗結果。

### 敏感病例定義 `sensitive`

- 餐後 3–48 小時出現至少一項主要腸胃症狀。

### 嚴格病例定義 `strict`

- 餐後 5–30 小時發病；
- 且嘔吐或腹瀉至少一項；
- 並伴隨噁心或腹部絞痛。

### 實驗室支持病例 `lab_supported`

- 符合敏感病例定義；
- 且 `YL-NAAT` 或 `YL-Culture` 陽性。

它僅供三角驗證，不作為主要食品發病率分析的唯一病例定義。

## 9. 背景發生率

即使沒有本次群聚：

- 每 100 人每天約 2–3 人可能出現至少一項腸胃症狀。
- 每 100 人每天約 1–1.5 人可能符合主要病例定義。
- 背景病例通常檢驗陰性，發病時間也不一定集中於預期潛伏期。

## 10. 必須避免的推論

- 金玉良是第一位被記錄的人，不等於第一位感染者、零號病人或污染來源。
- 未食用某食品但發病，不足以單獨排除該食品是群聚主因。
- 檢驗陰性不代表一定沒有感染。
- 相同分型不能取代暴露與時間鏈。
- 粗 OR 最大的食品不一定是真正病因。
- `p < 0.05` 不等於已證明因果；`p >= 0.05` 也不等於已證明沒有關係。
- 問卷未回覆不能編碼成非病例或未食用。
- 溫度與菌量是病因路徑的一部分，不宜機械式放入主要食品總效果模型。
- 不應把病例定義中的檢驗結果再當成同一模型的獨立預測變項。

## 11. 分母原則

| 問題 | 分母 |
|---|---|
| 參與人數與場地人數 | 完整名冊 |
| 問卷回覆率 | 完整名冊 |
| 病例比例 | 病例資料足以分類者 |
| 某食品食用者／未食用者發病率 | 該食品暴露與病例狀態均已知者 |
| 某檢驗陽性率 | 接受該項檢驗且結果有效者 |
